# 产品档案页面上下文

修改本目录前必须阅读：

1. `hive/business-docs/product/README.md`。
2. `hive-admin-go/business-docs/product/CONTEXT.md`。
3. `hive-admin-go/business-docs/product/product-archive.md`。
4. 涉及价格时再读 `hive-admin-go/business-docs/product/sku-price.md`。
5. `hive/business-docs/product/product-archive-ui.md`。

后端文档定义业务规则，本目录只实现页面入口、按钮权限和表单联动。任何产品层级、行版本、价格期间、追溯模式或权限变化必须同步文档。
