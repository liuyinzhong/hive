# ERP 页面局部规则

修改本目录任一模块前，必须先阅读仓库根 `business-docs/erp/README.md`、当前模块 UI 文档，以及后端仓库 `business-docs/erp` 下对应的领域词汇和业务规则。

- 后端业务手册决定操作是否允许及其业务副作用。
- 前端只根据后端状态与权限改善入口展示，不能替代后端校验。
- 页面行为变化时同步维护对应 `business-docs/erp/*-ui.md`。
- 若文档、接口类型和页面实现不一致，先列出差异和影响，再决定修改方向。
- 修改库存余额异步导出时，还必须阅读前后端 `business-docs/system` 的下载中心规则。
