# 表单必填校验按节点字段权限分步执行

> 方案日期：2026-09-23。改动集中在 hive-admin-go（后端校验语义对齐前端）；前端经核实已按目标语义实现，零改动。

## Problem Statement

流程关联表单的必填字段（如"预计上线时间"）若在发起节点被配置为隐藏，发起时后端仍按完整 Schema 全量校验必填，接口 `POST /api/workflow/instances` 报"请填写预计上线时间"，流程根本发不起来。但该字段的设计意图是"在后续某个把它设为可编辑的审批节点才填写"，发起时报错不符合业务语义。

## Solution

必填校验从"发起即按完整 Schema 全量校验"改为"每一步只对当前节点可编辑且必填的字段校验"。发起按发起节点字段权限（未配置默认可编辑），审批同意按该审批节点字段权限（未配置默认只读）；隐藏/只读的必填字段不拦截——说明流程还没走到应该填写它的节点。

## User Stories

1. 作为流程发起人，我想在发起节点隐藏"预计上线时间"这类后续才填的必填字段时，发起不被"请填写必填字段"拦截。
2. 作为审批人，当我所在节点把某必填字段设为可编辑时，我必须填写该字段才能同意通过（即使我没有修改任何其它字段）。
3. 作为审批人，当我所在节点对某必填字段是隐藏或只读时，即使该字段当前为空，我的同意操作不被它拦截。
4. 作为流程发起人，我提交的非空字段值（格式、长度、范围、枚举）在发起和审批时仍被完整校验，脏数据进不了流程变量。
5. 作为流程设计者，我可以自由安排必填字段在哪个节点填写，而不必为了发起能通过而放弃必填约束或隐藏配置。

## Implementation Decisions

- **校验语义**：必填类规则（`required`、`selectRequired`）仅对当前节点字段权限为可编辑的字段生效；隐藏与只读字段豁免必填。格式类规则（长度、数值、正则、枚举等）维持对已提交非空值的全量校验。与前端既有实现一致（前端对非可编辑字段清除校验规则，发起与审批表单共用同一工具函数）。
- **发起**：发起时从画布解析开始节点字段权限，未配置字段按默认可编辑处理（沿用 WF-DEF-016 默认值）；必填校验范围 = 可编辑字段。
- **审批同意**：必填校验范围 = 当前节点显式设为可编辑的字段（审批节点未配置默认只读，豁免必填）。**空变更同样校验**：审批人未修改任何字段直接同意时，仍按本节点可编辑字段校验必填，堵住"不改直接同意"绕过必填的路径。字段变更仍只允许可编辑字段（现状不变）。
- **拒绝路径不校验表单**（现状不变）；拒绝终止流程，无需补填。
- **不做终局兜底**：必填字段全程无节点可编辑时，实例允许正常结束、字段恒空，由流程设计者保证配置合理（用户拍定）。
- **公共校验函数改造**：表单值校验函数增加"必填生效字段集合"参数（传 `nil` 表示全部字段必填生效，保持既有调用与测试兼容；传非 nil 空集合表示全部字段豁免必填），发起与审批两处传入各自的可编辑字段集合。
- **前端零改动**：发起与审批表单已按权限渲染并清除非可编辑字段校验规则，`POST` 提交剔除隐藏字段，均与目标语义一致。
- **存量影响**（用户确认：存量数据由用户自行清理，不做兼容保留）：
  - 发起侧为放宽：此前因隐藏必填被拒的流程可正常发起。
  - 审批侧对"空变更直接同意且本节点存在未填的可编辑必填字段"的场景由放行变为拦截，属语义修正。
  - 无数据库结构变更、无接口契约变更（仅校验行为与错误时机变化）。
- **文档同步**（同一次交付）：WF-RUN-002 重写（发起校验按发起节点权限裁剪必填）；WF-RUN-022 重写（审批同意按节点可编辑字段校验必填、空变更同样校验）；前端设计器 UI 文档中"发起节点不应隐藏必填字段否则被拒"的旧警告改为新语义说明。
- **无需 ADR**：校验时机规则演进，规则正文（WF-RUN-002/022）可完整承载，无难以逆转的架构取舍。

## Testing Decisions

- 后端：`go build ./...`、`go vet ./...`、`go test ./...`；既有表单校验测试同步维护新参数（空集合语义保持原断言），并补必填豁免与空变更拦截的行为断言（沿用既有测试文件与风格）。
- 前端：无改动，不执行（本轮无前端 diff）。
- 手工验证路径：流程含必填字段"预计上线时间"→ 发起节点隐藏 → 发起成功；流转到将其设为可编辑的审批节点 → 不填直接同意被"请填写预计上线时间"拦截 → 填写后同意通过。

## Out of Scope

- 结束节点前的全量必填兜底校验（用户拍定不做）。
- 拒绝路径的表单校验。
- 表单设计器侧的必填配置提示增强（如提示"该字段无任何可编辑节点"）。
- 字段权限粒度细化（子字段独立权限）。

## Further Notes

- 需手动配置的数据：无。
- 用户确认的语义原话："在每一步只对可编辑且必填的字段进行校验。如果是隐藏的必填字段则不拦截。说明这个必填字段还没到应该填写的节点。"
