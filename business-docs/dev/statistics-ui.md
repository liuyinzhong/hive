# 开发统计 UI 规则

## 页面入口

- 版本详情按当前版本加载真实汇总、趋势和分布统计，是当前完整接入后端统计的页面。
- dashboard/analytics 只有需求、任务、缺陷概览，以及日趋势和年度工时两个图表连接开发统计 API；其它工时卡片、访问类图表仍含固定值或随机演示数据。
- dashboard/analytics 的日趋势当前固定查询 2026/02/25 与 2026/02/26，年度图固定查询 2026；它们不是自动随当天或用户筛选变化的生产口径。
- dashboard/workspace 的概览数字、天气和欢迎内容目前全部是 Vben 演示数据，没有调用开发统计 API。

## 数据呈现

- 日统计查询日期使用后端要求的 YYYY/MM/DD 格式；年度查询必须传有效年份。若把仪表盘改为动态日期，应先明确时区和默认范围。
- 概览接口返回的活跃数量按后端状态口径计算，前端不自行从分页列表重新统计。
- 多个统计请求独立处理 loading 和失败；单个图表失败不能用旧数据冒充当前筛选结果。
- 空结果展示明确空态或零值，图表组件卸载时清理实例和监听。

## 演示边界

- 固定数字、随机图表、固定日期和硬编码天气不得作为业务数据写入其它页面或测试断言。
- src/views/dev/versions/component 下的旧访问类图表当前未被版本详情引用，并含随机或演示数据；当前版本详情以 detail.vue 调用版本统计接口后的图表为准。
- 要把 analytics 或 workspace 变成正式业务仪表盘，必须逐个图表确定指标定义、数据范围、日期选择、权限和空态，再同步后端规则、API 类型和本页；不能只替换图表标题。

## 权限现状

统计接口当前主要依赖登录身份，没有逐图表原子权限；所有真实研发统计已由后端按当前角色数据范围聚合，与需求、任务、缺陷和版本来源列表一致。前端不能把结果描述为全公司总数，也不能从分页数据自行补全。
