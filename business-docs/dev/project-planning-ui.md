# 项目、模块与版本 UI 规则

## 项目和模块

- 项目主页展示项目列表或项目卡片，并从选中项目维护其模块；项目当前没有删除入口。
- 新增和编辑项目、模块分别使用弹窗，提交成功后刷新所属列表。
- 模块必须明确归属项目；切换项目后清空旧项目下的模块选择和表单状态。

## 版本

- 版本列表可按项目等条件筛选，新增或编辑时结束日期不能早于开始日期。
- 版本详情展示版本基础信息及需求、任务、缺陷等统计图表，统计失败应显示错误或空态，不能伪造零数据。
- 状态推进通过独立动作弹窗调用后端流转接口，页面不能只改本地状态。
- 只有草稿或后端允许状态的版本展示删除入口；最终是否允许以后端校验为准。
- “最新版本”数据用于默认选择时必须跟随当前项目重新请求。

## 已知差异

后端模块更新名称的唯一性检查当前可能按全局范围执行，而创建按项目范围执行。页面不能通过本地校验掩盖该差异；遇到冲突应保留表单并提示后端错误。
