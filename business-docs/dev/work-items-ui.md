# 需求、任务与缺陷 UI 规则

## 通用结构

- 需求、任务和缺陷分别提供列表、新增、批量新增、详情页面或抽屉，以及状态推进弹窗。
- 详情内展示基础信息和相关工作项；需求详情还展示关联任务、缺陷和变更时间线。
- 项目变化后重新加载版本和模块选项，并清理不再属于当前项目的旧选择。
- 提交、状态推进、删除成功后刷新当前列表或详情；失败保留输入内容。

## 状态和字段

- 页面状态选项来自当前字典或后端枚举，状态推进必须调用 next/flow 动作，不能直接用编辑接口写本地状态。
- 需求编辑只开放后端允许变更的状态、类型、级别和来源等字段；任务和缺陷同理，不展示后端不会保存的伪编辑项。需求新建和编辑表单不提供参与人编辑，参与人由状态推进弹窗指定的状态负责人产生。
- 需求状态推进弹窗在流转说明富文本上方提供「状态负责人」必选项（ApiSelect），候选为当前需求所属项目的成员；每次推进必须选定目标状态负责人，提交后由后端写入参与人关联表并推送通知。列表与详情响应的当前负责人为单对象字段 `thisUser`（无负责人时为 `null`），渲染时包装为单项数组复用 `UserAvatarGroup`。
- 需求列表查询表单提供「当前负责人」筛选（ApiSelect，数据源为所选项目的成员，随项目切换联动并在成员不匹配时自动清空），以所选用户视角查询名下需求，即该用户负责需求当前状态的记录；后端通过参与人关联表 EXISTS 子查询实现，不做负责人排序。
- 需求列表首列为复选框（已关闭需求行禁止勾选），工具栏「批量流转」按钮在勾选后可用：弹窗内选择统一目标状态、同一位状态负责人（流转到 99 时免选）和流转说明，提交调用批量流转接口，成功后刷新列表。
- 需求「批量新建」弹窗为可编辑表格（VTable），列依次为迭代版本、关联模块、需求标题、需求状态、需求类型、优先级；项目不展示，所有行继承列表当前查询项目；新行预填状态/类型/优先级为 0；描述和附件在批量入口不提供，需要时创建后单条编辑补充。提交时完全空行跳过，部分填写行校验标题/版本/模块并提示行号，通过后调用批量创建接口，成功后刷新列表。
- 任务开始和结束日期联动，结束日期不能早于开始日期。
- 缺陷确认和缺陷状态推进是两个不同动作；确认结果改变状态时，以动作响应和重新查询为准。
- 缺陷列表以「打回次数」列只读展示后端返回的 `returnNum`；该值由流转到待修复（bugStatus=10）时后端累计，前端不提供编辑入口，流转成功后随列表刷新更新。规则正文见[研发工作项规则](../../../hive-admin-go/business-docs/dev/work-items.md)。
- 删除按钮只在草稿状态显示，后端仍执行最终状态校验。
- 列表、全量选项、详情和动作均使用后端当前数据范围。需求参与人、任务执行人、缺陷处理人以及关联版本/需求/附件选项可能被收窄；空选项不能回退到未受限接口，保存越界引用时保留表单并展示后端错误。

## 任务导出与甘特图

- 任务列表按当前标题、项目、版本、状态、排序和 VXE 远端导出配置创建异步导出任务；创建成功后引导用户到下载中心，不直接生成本地文件。Worker 使用执行时的当前数据范围，最终行数可能因授权变化而不同。
- 甘特图是任务时间数据的另一种展示，不改变任务日期或状态。
- 下载任务规则见 [下载中心 UI](../system/download-center-ui.md)。

## 变更时间线

新增、字段修改、状态推进和删除由后端追加变更记录。前端时间线只读展示，不能把缺失时间线等同于操作未发生。

## 附件预览

- 需求详情页在「富文本预览」下方渲染附件表格，展示详情接口返回的 `fileList` 字段；`fileList` 为空时不渲染该区块。
- 附件表格使用 `useVbenVxeGrid` 静态数据模式：通过 `:table-data="fileList"` 传入数据，禁用分页（`pagerConfig.enabled: false`）、工具栏（`toolbarConfig.enabled: false`）与远程加载（`proxyConfig.autoLoad: false`）。
- 列包含文件名、类型（扩展名）、大小（前端格式化为 B/KB/MB）、上传人、上传时间和操作列；操作列使用 `VbenTableAction` 渲染「预览」按钮。
- 附件预览统一调用公共方法 `onPreview`（位于 `#/utils/preview`），仅传入文件 URL：`onPreview(row.url)`。函数内部用 `getFileNameFromUrl` 从 URL 推导扩展名，按扩展名分流——图片类型（jpg/jpeg/png/gif/bmp/webp/svg）使用 antd-vue `Image` 函数式预览（动态挂载、关闭自动清理、不离开当前页面）；其他类型调用 `previewWithKkFileView` 在新窗口通过 kkFileView 渲染。
- 相对 URL 由 `onPreview` 用 `window.location.origin` 自动拼接为同源绝对 URL；`/uploads/**` 为公开静态 URL，无需短时 token，私有文件需调用方先换取签名 URL 再调用。
- `onPreview` 内部对 kkFileView 配置缺失、URL 为空等情况统一以 `message.error` 提示。
