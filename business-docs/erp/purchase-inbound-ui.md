# 采购入库 UI 行为

业务规则以 [后端采购入库文档](../../../hive-admin-go/business-docs/erp/purchase-inbound.md) 为准。

## 页面入口

- 列表：`apps/web-antdv-next/src/views/erp/purchaseInbound/list.vue`。
- 创建：从采购单列表的“收货”动作打开，不在采购入库列表提供直接新增按钮。
- 详情和整单库存流水：从采购入库列表行操作打开抽屉。

## 创建交互

- 打开抽屉时先加载采购单详情，展示采购单号、供应商和仓库。
- 表单只允许选择该采购单的剩余采购明细。
- 一条采购明细可以按不同批号或有效期拆成多行。
- 同一提交中，采购明细、批号和有效期完全相同的行不能重复。
- 同一采购明细的本次入库数量合计不能超过剩余数量。
- 必须追溯的产品通过追溯码录入数量，数量等于追溯码条数；同次提交不能跨行重复追溯码。
- 提交成功后提示系统生成的入库单号，关闭抽屉并刷新来源列表。

## 只读边界

采购入库单提交后只提供列表、详情和关联库存流水查看，不提供编辑、删除、撤销或状态操作。

列表、详情、打印和关联流水受后端数据范围限制；从采购单创建入库前还必须能访问来源采购单，前端行按钮和缓存采购单 ID 不构成授权。
