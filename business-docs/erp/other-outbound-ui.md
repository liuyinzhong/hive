# 其它出库 UI 行为

业务规则以 [后端其它出库文档](../../../hive-admin-go/business-docs/erp/other-outbound.md) 为准。

## 页面入口

- 列表：`apps/web-antdv-next/src/views/erp/otherOutbound/list.vue`。
- 新建：列表工具栏抽屉。
- 详情和整单库存流水：列表行操作抽屉。

## 新建交互

- 新建表单默认出库日期为当天，并至少保留一条明细。
- 必须先选择仓库，明细库存余额只查询当前仓库的正库存。
- 已有明细后切换仓库需要确认；确认后清空明细，取消则保留原值。
- 库存余额选项只使用后端当前数据范围；任何明细在提交前失去访问权时整单失败，页面保留表单并重新加载选项。
- 同一 `balanceId` 不能重复选择。
- 无需追溯的产品填写正整数数量；必须追溯的产品选择追溯码，数量由码数计算。
- 提交前批量查询最新余额并提示可能的库存不足，但仍允许提交；后端事务校验是最终依据。
- 关闭已修改表单时确认是否丢弃；成功提交后直接关闭并刷新列表。

## 只读边界

其它出库单提交后不提供编辑、删除、撤销或状态操作。列表只提供详情和关联库存流水查看。

列表、详情和来源流水按当前数据范围返回；前端不能用仓库筛选或本地缓存扩大记录集合。
