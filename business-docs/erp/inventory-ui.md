# 库存与追溯码 UI 行为

业务规则以 [后端库存文档](../../../hive-admin-go/business-docs/erp/inventory.md) 为准。

## 库存余额页面

- 页面：`apps/web-antdv-next/src/views/erp/inventory/list.vue`。
- 主表展示库存余额，不允许直接编辑或删除。
- 工具栏按权限展示导出和期初库存入口。
- 库存流水从余额行操作打开，标题包含产品编码、名称和批号。
- 导出沿用当前筛选条件创建后台下载任务，不在页面同步生成文件。
- 余额、流水和追溯码结果由后端按当前数据范围过滤；其它出库的余额选项也只能使用当前可见记录，不提供绕过范围的备用查询。
- 导出进度、文件有效期和下载交互以 [下载中心 UI](../system/download-center-ui.md) 及后端下载中心规则为准。

## 期初库存

- 一次表单只选择一个仓库并批量维护明细。
- 同一批次维度的重复行在前端提交前拦截。
- 无需追溯的产品录入数量；必须追溯的产品录入追溯码，数量由码数计算。
- 同次表单中的追溯码不能跨行重复。
- 提交成功提示来源批次号和生成的流水数量，然后关闭弹窗并刷新余额列表。

## 追溯码页面

- 页面：`apps/web-antdv-next/src/views/erp/traceCode/list.vue`。
- 支持按追溯码、产品编码、批号、仓库和状态查询。
- 可从追溯码行查看该码关联的库存流水。
- 公共追溯码录入组件位于 `apps/web-antdv-next/src/views/erp/components`，由期初库存、采购入库和其它出库复用。

## 权限

- 余额列表、导出、余额流水和期初库存使用各自独立权限码。
- 追溯码列表和单码流水使用各自独立权限码。
