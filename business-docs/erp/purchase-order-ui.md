# 采购单 UI 行为

业务状态与操作条件以 [后端采购单文档](../../../hive-admin-go/business-docs/erp/purchase-order.md) 为准。

## 页面入口

- 列表：`apps/web-antdv-next/src/views/erp/purchaseOrder/list.vue`。
- 创建/编辑：列表页抽屉。
- 详情与操作日志：列表页详情抽屉。
- 采购入库：从允许收货的采购单行操作打开采购入库抽屉。

## 状态动作

| 状态 | 页面展示的动作 |
|---|---|
| `DRAFT` | 详情、编辑、确认、取消 |
| `WAITING_RECEIPT` | 详情、收货、取消 |
| `PARTIAL_RECEIPT` | 详情、收货、关闭 |
| `COMPLETED` / `CANCELLED` / `CLOSED` | 详情 |

每个动作还必须满足对应权限码；前端状态判断只用于交互，后端负责最终校验。

列表、详情、日志和状态动作只处理后端当前数据范围内的采购单。记录在权限收紧后消失或动作被拒绝时刷新列表并展示错误，不能继续使用缓存详情发起收货。

## 表单规则

- 新建默认采购日期为当天。
- 采购单至少包含一条明细。
- 同一产品品规不能重复选择。
- 数量必须为正整数，单价必须大于零且最多四位小数。
- 编辑时加载详情并提交 `expectedRowVersion`。
- 确认前展示二次确认。
- 取消和关闭使用文本框收集必填原因，最长 500 字符。
- 详情有日志权限时并行加载操作日志；无日志权限时只展示采购单详情。
