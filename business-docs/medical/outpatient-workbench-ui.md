# 医生工作台与处方审核 UI

业务状态、前置条件、事务、副作用和权限正文见后端 [医生接诊与处方规则](../../../hive-admin-go/business-docs/medical/outpatient-workbench-draft.md)。

## 页面入口

- 医生工作台：完整页面，权限码 `medical:doctorWorkbench:access`。
- 处方审核：分页列表和审核详情抽屉，权限码 `medical:prescriptionReview:access`。
- 疾病诊断档案：标准分页 CRUD 页面，权限码见后端规则。

首期沿用已确认的原工作台布局，不按 ABC 诊所管家的三栏界面调整；ABC 仅作为未来可选参考。

## 医生工作台

- 左侧展示当前医生当天已发布且未停诊的排班，以及所选排班的完整候诊队列。
- 排班没有候诊患者时按空队列展示；前端 API 在接口边界将异常的 `null` 集合兼容为空数组，覆盖候诊队列、病历诊断、处方及其明细，避免空状态渲染报错。
- 页面初次加载选中接口返回的第一条排班；医生可以手动切换，不应用额外的自动优先级规则。
- 候诊队列始终显示服务端脱敏后的姓名和手机号。
- “叫下一位”只在当前排班没有已叫号或接诊中患者时可用；其它叫号、过号、重新叫号和开始接诊按钮按候诊状态显示。
- 开始接诊后右侧展示完整患者信息和门诊病历；双击或点击“打开病历”可查看当天已开始或已完成的病历。
- 门诊病历采用文档式结构化录入。点击黄色占位后在原位置填写，字段失焦后延迟自动保存。
- 页面展示待保存、保存中、已保存或保存失败状态。完成接诊前强制执行最后一次保存，再由后端校验必填字段、主要诊断和处方状态。
- 疾病诊断从启用档案中选择。首条默认主要诊断，点击诊断标签可切换主要诊断。
- 历史病历使用只读抽屉展示；普通处方使用处方抽屉编辑。

## 处方抽屉

- 一份门诊病历可以新建多张普通处方。
- 草稿和审核不通过处方可以编辑；接诊完成后仅审核不通过处方仍允许编辑和重新提交。
- 药品从启用的 `DRUG` SKU 中选择。给药途径读取 `MED_MEDICATION_ROUTE` 字典，用药频次使用前端固定枚举。
- 可计算频次的发药数量由后端保存时计算；必要时、需要时由医生填写最小单位总量。
- 待审核处方只允许撤回，审核通过和已作废处方只读。

## 处方审核

- 列表默认显示待审核、审核通过和审核不通过处方。
- 详情展示提交版本的药品明细、诊断快照和过敏史快照。
- 审核通过意见选填；审核不通过意见必填。
- 审核完成后保留抽屉并刷新列表，方便查看结果。

## 疾病诊断档案

- 列表支持按 ICD 编码、名称、拼音和状态查询。
- 新增、修改使用抽屉；启停使用列表状态开关；删除需要二次确认。
- 页面不提供 Excel 导入。
