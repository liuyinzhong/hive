# 患者档案 UI 规则

## 列表与详情

- 列表支持按患者编号、姓名、证件、手机号和状态等条件查询，列表中的证件和联系方式始终按后端脱敏结果展示。
- 新增和编辑使用表单抽屉，详情使用只读抽屉；完整敏感字段是否返回由 medical:patient:viewSensitive 决定。
- 当前没有删除按钮或批量删除入口。

## 表单联动

- 创建时患者编号由后端生成，状态默认启用。
- 性别和证件类型读取启用字典；居民身份证、11 位手机号和出生日期按后端规则提供提前校验。
- 紧急联系人姓名、关系和电话三项联动：填写任一项后提示补齐全部，清空时作为整组清空。
- 保存或状态切换成功后刷新当前行；唯一身份冲突时保留表单供用户核对，不能自动合并患者。
