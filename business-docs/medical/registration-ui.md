# 挂号与候诊 UI 规则

业务正文见后端 [挂号主流程](../../../hive-admin-go/business-docs/medical/registration.md) 和 [候诊队列规则](../../../hive-admin-go/business-docs/medical/visit-queue.md)。

## 列表和创建

- 列表按挂号单号、患者、医生、科室、日期和状态等条件查询，状态标签统一使用前后端当前枚举。
- 新建挂号使用抽屉：选择启用患者，再选择未来已发布且有剩余号源的排班/档位；费用、医生和科室按排班快照只读展示。
- 患者、实际排班、挂号列表和动作都受后端当前数据范围限制；下拉为空或记录刷新后消失时不能请求未受限备用数据。
- 切换患者、排班或档位时清理不再适用的旧选择；提交期间禁用重复确认，最终号源以后端锁和事务为准。
- 创建成功后刷新列表；号源冲突时保留抽屉并重新加载可用号源。

## 状态动作

| 当前状态 | 页面可提供动作 |
|---|---|
| 待支付 0 | 支付、取消 |
| 已支付 10 | 签到、标记爽约、发起退款 |
| 已签到 30 | 只查看候诊信息；完成接诊仅在医生工作台 |
| 退款申请中 80 | 推进退款处理中 |
| 退款处理中 90 | 确认已退款 |
| 已完成、已取消、已爽约、已退款 | 只读 |

- 取消、退款等需要原因的动作必须在弹窗中收集有效原因。
- 爽约动作只有号源时段结束后才展示或可用；后端仍执行最终时间校验。
- 所有动作成功后使用响应并重新查询，不能仅修改本地状态标签。

## 签到与详情

- 已支付挂号单的签到按钮使用 medical:registration:checkIn 权限。
- 签到成功后直接使用动作响应的 queueInfo.queueSequence 提示候诊序号，并刷新列表。
- 详情接口返回非空 queueInfo 时展示候诊序号、候诊状态、叫号次数和签到时间；未签到时不展示候诊区块。
- 挂号管理不提供调试用完成接诊按钮。正式完成只能从医生工作台执行。
