# 医生管理 UI 规则

## 页面结构

- 左侧科室树筛选医生，右侧表格支持关键词、职称、用工类型和状态等查询。
- 新增和编辑共用表单抽屉；编辑时按医生 ID 重新加载详情。
- 详情使用只读抽屉展示基础信息、出诊科室和服务能力。
- 单行删除弹出确认框，成功后刷新列表。

## 按钮与权限

| 入口 | 展示权限 |
|---|---|
| 新增 | `medical:doctor:create` |
| 详情 | `medical:doctor:detail` |
| 编辑 | `medical:doctor:update` |
| 删除 | `medical:doctor:delete` |
| 状态开关 | 后端要求 `medical:doctor:status` |

当前列表状态开关组件没有显式配置前端 `auth`，但请求仍受后端 `medical:doctor:status` 保护。后续修改该列表时应补齐按钮可见性，避免无权限用户看到可操作开关后收到 403。

## 表单联动

- 创建时默认状态启用，其余开关和默认接诊时长以表单 Schema 的默认值为准。
- 出诊科室使用临床科室树多选；主科室使用同一科室数据源单选。
- 主科室必须包含在已选出诊科室中，前端表单与后端均应保持该约束；不能只保存主科室名称。
- 绑定用户从系统用户选项选择，但用户是否启用及是否已绑定其他医生以后端返回为准。
- 头像在接口 URL 字符串与上传组件文件数组之间转换，不改变后端存储语义。
- 提交成功关闭抽屉并刷新列表；失败保留表单供用户修正。
