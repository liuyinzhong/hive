# 流程运行 UI 规则

## 页面

- “我发起的”只展示当前用户发起的实例；待办/已办按任务办理人展示；抄送列表按接收人展示。
- 流程详情展示定义快照、流转轨迹、表单快照和当前用户可执行动作。
- 发起弹窗根据已发布定义和绑定表单动态渲染字段，提交时保留后端校验错误。

## 审批动作

- 同意、拒绝、转办、加签、减签、退回和撤销使用独立动作弹窗或确认框，成功后刷新实例详情和相关列表。
- 节点字段权限决定隐藏、只读和可编辑表现；前端禁用不能代替后端字段权限校验。
- 转办不能选择自己；加签人数和审批组上限在前端提前提示，最终以后端为准。
- 退回目标只展示后端返回的已经过审批节点，不允许任意输入节点 ID。
- 抄送阅读只更新已读状态，不显示审批按钮。

## 权限注意

当前部分运行时按钮主要依据任务状态和接口结果展示，页面未统一发现显式原子权限指令；后端路由权限和参与者校验仍会执行。后续调整动作按钮时应同步核对权限码、参与者范围和状态，不能仅凭前端状态放行。
