# 流程定义与设计器 UI 规则

## 定义列表

- 列表提供新增、编辑基础资料、进入设计器、发布、启停和删除等入口；动作可见性同时受权限和定义状态控制。

- 新建定义从版本 0 草稿开始；发布、启停或删除成功后重新查询列表。

- 删除前二次确认；历史实例是否仍可查看以后端快照规则为准。

## 设计器

- 左侧节点面板提供开始、审批、条件、抄送和结束节点，画布维护连线，属性面板编辑当前节点。

- 绑定表单后，条件和字段权限只能选择该 Schema 字段；切换 Schema 时清理失效引用并明确提示。

- 关联表单选择框旁提供“编辑表单”入口，跳转到该表单的表单设计器页面；未选择表单时入口禁用。

- 字段权限支持发起节点和审批节点：发起节点未配置字段默认可编辑，审批节点默认只读；发起节点不应隐藏配置了必填规则的字段，否则发起会被后端表单校验拒绝。

- 审批节点配置办理人来源和或签/会签；条件节点配置结构化规则、优先级和唯一默认分支。

- 定义表单的业务类型为必填下拉（BUSINESS_TYPE 字典），节点可挂载的自动化动作按此过滤；启动类型单选手动发起（默认）或被动触发。新增/编辑表单提供"默认流程"开关：仅启动类型为被动触发时可操作，手动发起时禁用且恒为关；业务类型或启动类型变化时联动清空，勾选保存后自动顶掉同业务类型原默认。列表"默认流程"列以金色标签展示当前默认，无独立设置按钮。

- 被动触发流程的设计器中"关联表单"下拉禁用并提示原因（由业务对象自动发起，没有发起人填表单环节）；定义改为被动触发时后端自动解绑已关联的表单。

- 自动化动作管理是独立页面（工作流 → 自动化动作）：查询支持名称、业务类型、状态；列表展示动作名称、业务类型（字典翻译）、动作类型、动作摘要、状态、备注。动作摘要按类型渲染：修改字段值为"目标字段 → 目标值"，插入记录为"插入XX:字段…"。新建/编辑弹窗按动作类型渲染参数区：修改字段值走"业务类型 → 目标字段（状态白名单）→ 目标值（字典下拉）"联动；插入记录为"目标业务类型 + 按可插字段目录逐行配置映射（字段[必填带*] / 值来源[固定值|表单字段] / 值[字典下拉或输入框|表单字段名]）"，必填字段未配置映射时保存拦截。

- 所有节点类型的属性面板提供「自动化动作」区块：底部选择器按定义业务类型过滤启用动作，选中即快照挂载（同一动作同节点只挂一次），挂载项按动作类型展示摘要；含"表单字段"来源的动作挂载时按当前流程绑定表单即时警告缺失字段（不阻断，发布校验为最终依据）；支持上移/下移（顺序即执行顺序）与移除；区块文案说明快照语义。

- 保存设计只保存草稿；发布是独立动作，并展示后端图结构、表单、办理人和自动化动作快照校验错误。

- 设计器的客户端连线限制用于提前反馈，后端发布校验是最终依据。
