# 流程定义与设计器 UI 规则

## 定义列表

- 列表提供新增、编辑基础资料、进入设计器、发布、启停和删除等入口；动作可见性同时受权限和定义状态控制。
- 新建定义从版本 0 草稿开始；发布、启停或删除成功后重新查询列表。
- 删除前二次确认；历史实例是否仍可查看以后端快照规则为准。

## 设计器

- 左侧节点面板提供开始、审批、条件、抄送和结束节点，画布维护连线，属性面板编辑当前节点。
- 绑定表单后，条件和字段权限只能选择该 Schema 字段；切换 Schema 时清理失效引用并明确提示。
- 审批节点配置办理人来源和或签/会签；条件节点配置结构化规则、优先级和唯一默认分支。
- 保存设计只保存草稿；发布是独立动作，并展示后端图结构、表单和办理人校验错误。
- 设计器的客户端连线限制用于提前反馈，后端发布校验是最终依据。
