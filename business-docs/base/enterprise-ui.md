# 企业主体 UI 规则

## 页面结构

- 列表支持按编码、名称、主体类型、业务角色和状态筛选。
- 新增、编辑和详情使用抽屉；创建编码由后端生成，页面不允许手工伪造。
- 状态开关成功后使用后端返回数据或重新查询当前行，保持行版本一致。

## 表单联动

- 主体类型为企业、医疗机构、个体工商户、事业单位或其它。
- 生产企业、上市许可持有人、注册人、备案人、进口代理、供应商、经销商、分销商和客户等业务角色至少选择一项。
- 业务角色和关联资料按完整集合保存；未在提交集合中的旧角色会被移除。
- 编辑和状态动作必须携带当前 rowVersion；并发冲突后提示用户重新加载，不覆盖他人修改。

## 选择器

其它模块的企业下拉只显示启用主体，并可按业务角色筛选。页面选择成功不代表后端放弃角色和状态复核。
