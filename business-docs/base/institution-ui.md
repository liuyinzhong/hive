# 本机构 UI 规则

## 页面结构

- 本机构是单例资料页，不展示多行列表，也不提供新增、删除或状态切换入口。
- 页面加载详情；后端尚无机构记录时显示可编辑空表单，保存动作负责首次创建。
- 机构基础资料与资质、联系人、地址、银行账户在同一页面维护。

## 表单联动

- 机构类型当前固定为医院；统一社会信用代码按后端字符规则校验。
- 资质有效期结束日不能早于签发日。
- 联系人、地址和银行账户分别最多一个主联系人、主地址或默认账户，选择新的主项时页面应取消同组其它主项。
- 子项数组按完整集合提交；删除页面中的一行表示保存后删除该旧子项，不能只提交增量。
- 保存成功后重新加载详情，避免继续编辑过期的聚合数据。

## 权限

页面读取使用本机构详情权限，保存使用本机构更新权限。前端只读展示不能替代后端权限。
