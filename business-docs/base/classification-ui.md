# 分类体系 UI 规则

## 页面结构

- 页面左侧维护分类体系，右侧显示当前体系的分类节点树；切换体系后重新查询节点，不能混用旧树。
- 分类体系和节点分别使用表单抽屉或弹窗维护；节点表单的父节点只能来自当前体系。
- 筛选节点树时保留祖先路径，清空筛选恢复完整树。

## 交互与限制

- 体系编码、节点编码和名称按后端唯一性规则提交，前端异步校验只提供提前提示。
- 父节点选择器排除当前节点及其后代，避免形成环。
- 有子节点的体系或节点删除会被后端拒绝；页面应保留数据并展示错误，不应乐观移除。
- 状态切换和编辑携带 rowVersion；冲突时重新加载。
- 业务选项接口只返回启用节点，管理树仍需展示停用节点供维护。
