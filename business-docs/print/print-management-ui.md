# 打印管理 UI 规则

## 模板列表

- 当前每种单据类型最多一份模板；首期仅显示采购入库单类型。
- 列表提供创建或进入设计器、预览、发布和删除入口，并按打印模板权限控制。
- 草稿和已发布状态分别展示；保存草稿后不能把页面标记为仍然已发布。

## 设计器

- 设计器维护 A4 方向、页边距、区块、文本、字段和明细表格等元素。
- 可选字段只来自当前单据类型的后端元数据注册表，不能手工输入任意字段路径。
- 拖拽、缩放和属性编辑只修改本地草稿；点击保存后提交完整布局和 rowVersion。
- 并发冲突时提示重新加载，不能用旧 rowVersion 强行覆盖。
- 发布前先保存需要发布的草稿，再执行独立发布动作；发布失败仍保留草稿供修正。

## 预览与打印

- 模板预览使用当前草稿，可选择采购入库单 ID 或示例数据检查版式。
- 正式采购入库单打印使用已发布版式，设计器未发布修改不能进入正式结果。
- 真实采购入库单的预览和正式打印都继承来源单据的数据范围；模板预览或打印按钮权限不能使越界单据可见。
- preview.vue 负责浏览器呈现和打印；页面关闭、浏览器打印或另存 PDF 不改变来源单据状态。
