# 支付渠道 UI 规则

## 页面结构

- 列表按渠道名称、类型、环境、状态和默认标记筛选，提供新增、编辑、状态、默认和删除动作。
- 渠道类型只显示微信支付和支付宝；环境只显示 development、testing、staging、production 的国际化标签。
- 新增和编辑弹窗维护名称、类型、环境、应用 ID、回调地址、差异化 JSON、状态和默认标记。

## 交互

- 差异化配置必须是空值或合法 JSON；页面应使用结构化编辑或明确校验错误，不自动修复用户内容。
- 把记录设为默认成功后，刷新整个列表以同步同类型同环境下其它记录被取消默认的结果。
- 取消默认不会自动选另一个渠道，列表允许当前维度没有默认项。
- 删除前二次确认，成功后按当前分页重新查询。

## 敏感信息

- 差异化配置可能包含支付密钥、证书路径或口令，页面不得输出到控制台、URL、普通埋点或错误详情。
- 当前后端可能返回完整配置；前端只能在有权限的编辑场景谨慎使用，不应扩散到列表列或复制按钮。
