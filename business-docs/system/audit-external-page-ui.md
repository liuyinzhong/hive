# 审计日志与外部页面 UI 规则

## 操作日志和登录日志

- 两类日志分别提供分页筛选、列表和详情抽屉，不提供新增、修改或删除。
- 日志列表和详情按日志用户应用当前角色数据范围；角色或部门变化后刷新结果可能减少，页面不能复用旧详情绕过后端查询。
- 操作日志按操作者、接口、结果和日期等条件查询；登录日志按账号、结果和时间等条件查询。
- 详情中的请求或响应内容按服务端结果展示，但前端不得再次写入控制台或复制到普通埋点。
- 日期筛选变化后从第一页重新请求；不能只过滤当前分页数据。
- 对可能含敏感内容的字段应使用脱敏或限制展示，支付密钥、Token 等不得直接呈现。

## 外部页面管理

- 外部页面通过系统菜单下的独立管理页面维护标题、稳定名称、/external 路径和状态。
- 新建时只能从前端已注册的静态外部路由候选中选择，名称和路径随候选带入；它不是任意 URL 或任意组件配置入口。
- 创建后名称不可编辑，路径只读；编辑表单不提供伪可改输入。
- 状态切换和删除成功后刷新列表，删除前二次确认。
- 公开访问同时要求静态路由候选和启用数据库记录的名称、路径完全一致；任一侧缺失或不匹配都进入未找到页。
- 列表“复制地址”复制当前公开路径；复制成功不代表记录已启用或访问一定通过双重登记校验。
- src/views/external/demo 是当前已注册的公开内容页，不获得后台管理动作。
- 外部页面与普通菜单、内嵌页面和外链菜单字段不同，表单不能混用其 layout 或 ignoreAccess 配置。
