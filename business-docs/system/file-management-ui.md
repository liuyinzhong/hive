# 文件管理 UI 规则

- 文件列表分页展示当前角色数据范围内的上传文件元数据，并按现有条件查询；不把下载中心导出文件混入此列表。
- 使用状态（status，0=已使用、1=未使用）作为查询条件和列表列展示：查询为精确匹配，可清空表示不过滤。当前所有上传入口产生的文件均为"已使用"，"未使用"由后续孤儿文件清理阶段写入。该状态表示文件是否被业务使用，不表示启用/禁用。
- 页面上传控件当前接受任意文件，未在选择前执行 200 MB 客户端校验；超过限制时由后端拒绝。若补前端校验，必须与后端上限保持一致。
- 上传成功后刷新文件列表；失败时移除前端临时 loading，不把本地选择误显示为已保存文件。
- 图片缩略图按后端返回地址展示；当前缩略图不保证压缩或固定尺寸。
- 预览动作在新窗口打开后端返回 URL；复制链接动作把同一 URL 写入剪贴板。当前 `/uploads/**` 是公开静态路径，知道 URL 即可访问；列表不可见不等于内容私有，敏感文件不得使用该入口。
- 当前页面没有删除动作，因为后端没有文件删除接口。不得只在前端隐藏一行冒充删除成功。
- 列表入口受 file:list 权限保护；上传接口当前只要求登录，后续增加原子权限时需同步全部上传调用方。
