# 字典与系统参数 UI 规则

## 字典

- 字典页面以树表维护同一字典类型的层级条目，支持新增、编辑、状态和删除。
- 新增子项时带入当前父节点和字典类型；父节点选择排除自身及后代。
- 父节点状态变化会影响后代，成功后重新查询整棵树，不能只切换当前行显示。
- 有子节点时删除会被后端拒绝，页面保留树结构并展示错误。
- 全局本地字典（`getLocalDictList` 等）通过公共字典树接口 `POST /system/dicts/values` 加载，仅需登录、不要求字典管理权限；字典管理页的查询、筛选和排序仍走受权限保护的管理接口。

## 系统参数

- 参数列表支持按键、名称、类型和公开状态等条件查询，新增和编辑使用弹窗。
- 参数类型为字符串、数字、布尔或 JSON；切换类型时使用对应编辑和校验方式，JSON 解析失败不能提交。
- 参数键使用大写字母、数字和下划线；程序依赖键不应在普通编辑中随意改名。
- 公开开关表示可通过公共参数值接口读取，不代表管理页面或全部参数对匿名用户开放。
- 参数页面不得用于录入密码、Token、私钥或连接串。
